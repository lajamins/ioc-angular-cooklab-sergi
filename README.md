# CookLab - Sergi Pérez Ariño

## Descripció

CookLab és una aplicació web de receptes que funciona com un laboratori culinari digital. Permet als usuaris descobrir receptes, guardar-les, filtrar per ingredients i experimentar amb nous plats de manera fàcil i intuïtiva.

L’objectiu principal és fer que cuinar sigui divertit, accessible i creatiu per a tothom.

## Stack Tècnic

- Angular 18
- Arquitectura Standalone
- Routing habilitat
- SCSS (Sass) per als estils
- Node.js v18.x / v20.x (LTS)
- NPM v9.x / v10.x
- Angular CLI v18
- Control de versions amb Git i GitHub
